# Airbnb Madrid: Que factores influyen en el precio y que diferencia a los Superhosts?

## Descripcion
Analisis de datos de ~25,000 alojamientos de Airbnb en Madrid para identificar que factores influyen en el precio y que caracteristicas diferencian a los Superhosts del resto.

## Dataset
- **Fuente:** [Inside Airbnb](https://insideairbnb.com/)
- **Ciudad:** Madrid, Espana
- **Fecha de los datos:** Septiembre 2025
- **Tamano:** ~25,000 listings con 79 variables

## Como reproducir el analisis

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/jul5289/proyecto-final-airbnb.git
   cd proyecto-final-airbnb
   ```

2. Crear un entorno virtual e instalar dependencias:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Abrir el notebook:
   ```bash
   jupyter notebook notebooks/analisis_airbnb.ipynb
   ```
